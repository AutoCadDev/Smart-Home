# SmartHome

## Projektbeschreibung

Dieses Projekt dient der Planung, Umsetzung und Dokumentation eines zentral gesteuerten Smart-Home-Systems für unsere Wohnung.

Als zentrale Plattform wird Home Assistant eingesetzt. Das System soll möglichst herstellerunabhängig, lokal steuerbar und langfristig erweiterbar aufgebaut werden.

Die Bedienung erfolgt über Smartphones sowie über ein zentrales Tablet-Dashboard in der Wohnung.

## Projektziele

- Zentrale Steuerung über Home Assistant
- Einfache Bedienung für die ganze Familie
- Integration von iPhones
- Zentrales Smart-Home-Tablet
- Smarte Beleuchtung
- Heizungssteuerung
- Raumklimaüberwachung
- Anwesenheitserkennung
- Sicherheitsfunktionen
- Automationen und Szenen
- Möglichst lokale und herstellerunabhängige Geräte
- Erweiterbare Systemarchitektur
- Dokumentation und Versionierung über Git

## Geplante Bereiche
