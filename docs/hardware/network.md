# Netzwerk & Stromversorgung

## Ziel

Stabile Netzwerk- und Stromversorgung für das gesamte Smart Home.

Die Smart-Home-Funktionen sollen auch bei vielen Geräten zuverlässig
funktionieren, ohne unnötige zusätzliche Bridges oder Netzwerkgeräte.

## Internet / Router

Vorhandene bzw. zukünftige Internetanbindung:

- Anschlussart: noch festlegen
- Router: noch festlegen
- Standort Router: nach Wohnungsaufmaß festlegen
- LAN-Anschlüsse in der Wohnung: prüfen

## WLAN

Beim Wohnungsaufmaß prüfen:

- [ ] mögliche Routerposition
- [ ] LAN-Dosen und Netzwerkverkabelung
- [ ] WLAN-Abdeckung aller Räume
- [ ] WLAN-Abdeckung Balkon
- [ ] Bedarf für Access Point / Mesh
- [ ] mögliche Position zusätzlicher Netzwerkgeräte

Zusätzliche Access Points oder Mesh-Systeme werden erst geplant,
wenn die Netzwerkstruktur der Wohnung bekannt ist.

## Thread / Matter

Der Echo Hub dient als zentrale Matter-/Thread-Komponente.

Aktuell kein zusätzlicher Thread Border Router vorgesehen.

Matter-over-Thread-Geräte können beispielsweise für Fensterkontakte
und weitere Sensoren verwendet werden.

## Zigbee / Philips Hue

Philips Hue Beleuchtung wird über die Hue Bridge Pro betrieben.

Die Hue Bridge Pro sollte möglichst zentral und mit stabiler
Netzwerkverbindung positioniert werden.

## Echo Hub

Geplanter Standort:

- Eingangs-/Flurbereich
- genaue Position nach Wohnungsaufmaß

Zu prüfen:

- [ ] Steckdose vorhanden
- [ ] WLAN-Empfang
- [ ] gute Erreichbarkeit
- [ ] sinnvolle Bedienhöhe
- [ ] alternativ PoE prüfen

## Hue Bridge Pro

Zu prüfen:

- [ ] Standort
- [ ] Stromversorgung
- [ ] Netzwerkverbindung
- [ ] möglichst zentrale Position für Hue/Zigbee

## Stromversorgung

Beim Wohnungsaufmaß erfassen:

- [ ] Steckdosen an geplanten Smart-Home-Positionen
- [ ] Stromversorgung Echo Hub
- [ ] Stromversorgung Hue Bridge Pro
- [ ] Stromversorgung vorhandener Echo-Geräte
- [ ] Stromversorgung geplanter Beleuchtung
- [ ] unnötige Verlängerungskabel vermeiden

## Kaufbedarf

Aktuell kein zusätzlicher Netzwerk-Kaufbedarf festgelegt.

Router, Mesh, Access Points, Switches oder PoE-Hardware werden erst
nach Prüfung der Wohnung festgelegt.
