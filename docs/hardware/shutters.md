# Rollladensteuerung

## Ziel

Prüfen, ob die vorhandenen Rollläden der Wohnung sinnvoll in das
Echo-Hub-/Alexa-Smart-Home integriert werden können.

Die bestehende Elektroinstallation soll möglichst unverändert bleiben.

## Vorhandene Installation

Noch zu erfassen.

Zu prüfen:

- Anzahl der Rollläden
- elektrisch oder manuell
- Hersteller / Modell
- Art der vorhandenen Wandschalter
- Verkabelung der elektrischen Rollläden
- vorhandene Zentralsteuerung
- eventuell bereits vorhandene Smart-Home-Funktion

## Gewünschte Funktionen

- Rollläden einzeln pro Raum steuern
- zentrale Steuerung über Alexa / Echo Hub
- weiterhin manuelle Bedienung am Wandschalter
- Zeitsteuerung
- Sonnenaufgang / Sonnenuntergang
- Abwesenheitsmodus
- später eventuell temperatur- oder sonnenabhängige Steuerung

## Prüfung beim Wohnungsaufmaß

- [ ] Anzahl aller Rollläden erfassen
- [ ] elektrisch / manuell erfassen
- [ ] vorhandene Schalter fotografieren
- [ ] Hersteller / Modell erfassen
- [ ] vorhandene Steuerung prüfen
- [ ] Smart-Home-Kompatibilität prüfen
- [ ] Matter / Alexa Integration prüfen
- [ ] notwendige Zusatzhardware bestimmen
- [ ] Kosten und Nutzen bewerten

## Kaufbedarf

Aktuell kein Kaufbedarf festgelegt.

Die Auswahl möglicher Rollladenaktoren oder smarter Steuerungen erfolgt
erst nach Prüfung der vorhandenen Installation.
