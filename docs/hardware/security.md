# Sicherheit & Wasserschutz

## Ziel

Einfache Sicherheits- und Schutzfunktionen in das Smart Home integrieren,
ohne eine klassische Alarmanlage aufzubauen.

Echo Hub / Alexa dient als zentrale Anzeige und Automationsplattform.

## Fenster und Türen

Bevorzugter Sensor:

- Aqara Door and Window Sensor P2
- Matter over Thread
- direkte Integration über Echo Hub
- keine zusätzliche Aqara Bridge erforderlich

Geplante Einsatzorte:

- Fenster in den Wohnräumen
- Fenster in den Schlafzimmern
- Fenster in den Kinderzimmern
- Fenster in den Bädern, sofern vorhanden
- Balkontür

Die genaue Anzahl wird beim Wohnungsaufmaß bestimmt.

## Wasserschutz

Wassersensoren sollen an Stellen eingesetzt werden, an denen
unbemerkter Wasseraustritt größere Schäden verursachen könnte.

Geplante Bereiche:

- [ ] Küche – unter Spüle / Geschirrspüler
- [ ] Hauptbad
- [ ] Gästebad

Optional später prüfen:

- [ ] Waschmaschine
- [ ] weitere wasserführende Geräte

Konkretes Sensormodell noch auswählen.

## Benachrichtigungen

Später geplante Automationen:

- Fenster / Tür ungewöhnlich lange offen → Hinweis
- Balkontür bei Abwesenheit offen → Warnung
- Wassersensor erkennt Wasser → sofortige Benachrichtigung
- optional Alexa-Sprachausgabe im Haus
- Status wichtige Fenster und Türen über Echo Hub

## Alarmanlage

Aktuell keine vollständige Alarmanlage geplant.

Fensterkontakte, Präsenzsensoren und Echo Hub sollen zunächst
für Status, Automationen und einfache Warnungen genutzt werden.

Eine Erweiterung um Sirene, Kamera oder weitere Sicherheitstechnik
kann später erfolgen.
