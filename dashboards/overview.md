# Smart Home Dashboard

## Ziel
Das Ziel ist es, eine zentrale Übersicht über die wichtigsten Informationen und Steuerungsmöglichkeiten des Smart Home Systems zu bieten. 
Das Dashboard soll auf einem zentralen Tablet im Haus angezeigt werden und die wichtigsten Informationen auf einen Blick darstellen. 
Die Icons und Farben sollen intuitiv verständlich und modern sein, um eine einfache Bedienung zu ermöglichen.
Das Dashboard soll modular aufgebaut sein, damit später weitere Funktionen wie Raumklima, Rollläden und Sensoren ergänzt werden können

## Hauptansicht
- Uhrzeit / Datum
- Wetter aktuell
- Wettervorhersage
- Räume
- Lichtstatus
- Türklingel-Kamera
- Hausstatus
- To do´s 
- Geburtstage
- Schnellaktionen
- Navigation
- Einstellungen

## Bereiche

### Kopfbereich

- Links: moderne analoge Uhr mit bewegten Zeigern
- Mitte: persönliche Begrüßung und aktuelles Datum
- Rechts oben: kompakte Wetteranzeige
  - aktuelles Wettersymbol
  - aktuelle Temperatur
  - Tagesminimum und Tagesmaximum
  - Regenwahrscheinlichkeit
- Raumtemperatur des Wohnbereichs

### Hauptbereich

- Übersicht der aktuell eingeschalteten Beleuchtung
- Status der Rollläden

### Info-Bereich

- Termine
- Geburtstage

### Schnellaktionen / Navigation

- Coming Home
- Leaving Home
- Einstellungen
